# 数据库设计文档

> 配套技术栈：MySQL 8.0 + MyBatis-Plus，所有表统一使用 InnoDB + utf8mb4_unicode_ci。
> 通用字段：`id` BIGINT 主键、`create_time`/`update_time`/`create_by`/`update_by`/`deleted`（逻辑删除）。
> 数据库名：`crm_db`

## 二、核心表字段设计

### 2.1 系统基础

#### sys_user（用户）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键 |
| dept_id | BIGINT | 部门 ID |
| username | VARCHAR(50) | 登录名（允许跨部门同名，无唯一约束） |
| password | VARCHAR(100) | BCrypt 加密 |
| real_name | VARCHAR(50) | 真实姓名 |
| phone | VARCHAR(20) | 手机号（NOT NULL，唯一，注册必填） |
| email | VARCHAR(50) | 邮箱（唯一，可为 NULL） |
| sex | TINYINT | 0未知 1男 2女 |
| avatar | VARCHAR(200) | 头像 URL |
| status | TINYINT | 0停用 1启用 |
| last_login_time | DATETIME | 最后登录时间 |
| dept_name | - | 非数据库字段（列表展示用，service 层回填） |

> 注：`username` 已移除唯一索引 `uk_username`，允许不同部门下存在同名用户。登录时通过用户名+密码组合定位唯一账号。逻辑删除用户的 phone/email 通过 `19-fix-user-unique-after-delete.sql` 清理以释放唯一索引。

## 五、SQL 脚本执行顺序

|---|---|---|

| 02 | init-customer.sql | 客户模块表 + 预设标签 |
| 03 | init-market.sql | 市场模块表 + 测试数据 |
| 04 | init-business.sql | 商机/合同/回款表 + 测试数据 |
| 05 | init-service.sql | 工单/售后记录表 + 测试数据 |
| 06 | init-message.sql | 系统消息表 |
| 07 | init-perms.sql | 全模块按钮权限（:add/:edit/:delete/:reset/:assign）+ 6 角色授权 |
| 08 | fix-unique-constraint.sql | 修复 DEFAULT '' + UNIQUE 冲突（改 DEFAULT NULL） |
| 09 | fix-menu-perms.sql | 统一菜单权限标识 + 销售经理菜单授权 |

| 12 | fix-password.sql | 修复测试账号密码哈希 |
| 13 | init-testdata.sql | 测试数据补充 |
| 14 | init-sign-in.sql | 外勤签到表 + 菜单 + 全角色授权 |
| 15 | fix-user-assign-perm.sql | 分配角色按钮权限（system:user:assign） |
| 16 | fix-menu-name.sql | 修复被 PowerShell 编码破坏的菜单名称 |
