# 数据库设计文档

> 配套技术栈：MySQL 8.0 + MyBatis-Plus，所有表统一使用 InnoDB + utf8mb4_unicode_ci。
> 通用字段：`id` BIGINT 主键、`create_time`/`update_time`/`create_by`/`update_by`/`deleted`（逻辑删除）。

## 二、核心表字段设计

### 2.1 系统基础

#### sys_user（用户）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键 |
| username | VARCHAR(50) | 登录名 |
| password | VARCHAR(100) | BCrypt 加密 |
| real_name | VARCHAR(50) | 真实姓名 |
| phone | VARCHAR(20) | 手机 |
| dept_id | BIGINT | 部门 ID |
| status | TINYINT | 0 停用 1 启用 |
| last_login_time | DATETIME | 最后登录 |

#### sys_role（角色）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键 |
| role_code | VARCHAR(50) | 角色码（ADMIN/MANAGER/SALE/MARKET/SERVICE） |
| role_name | VARCHAR(50) | 角色名 |
| data_scope | TINYINT | 数据范围 1本人 2本部门 3本部门及下 4全部 |

#### sys_menu（菜单/权限）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键 |
| parent_id | BIGINT | 父菜单 |
| name | VARCHAR(50) | 菜单名 |
| path | VARCHAR(200) | 路由路径 |
| component | VARCHAR(200) | 组件路径 |
| perms | VARCHAR(100) | 权限标识（如 `customer:add`） |
| type | TINYINT | 1目录 2菜单 3按钮 |

#### sys_dept（部门）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键 |
| parent_id | BIGINT | 父部门 |
| dept_name | VARCHAR(50) | 部门名 |
| ancestors | VARCHAR(500) | 祖级路径 |

#### sys_log（操作日志）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键 |
| user_id | BIGINT | 操作人 |
| operation | VARCHAR(200) | 操作描述 |
| method | VARCHAR(200) | 方法名 |
| params | TEXT | 请求参数 |
| ip | VARCHAR(50) | IP |
| cost_time | BIGINT | 耗时 ms |

### 2.2 市场获客

#### mkt_clue（线索）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键 |
| customer_name | VARCHAR(100) | 客户名称 |
| contact_phone | VARCHAR(20) | 联系电话 |
| source | VARCHAR(50) | 来源（展会/门店/抖音/微信/官网） |
| channel_id | BIGINT | 渠道 ID |
| region | VARCHAR(50) | 区域（温州各区县） |
| industry | VARCHAR(50) | 行业 |
| score | INT | 线索评分 |
| status | TINYINT | 1待分配 2已分配 3已转化 4已退回 |
| owner_id | BIGINT | 负责销售 ID |
| converted_customer_id | BIGINT | 转化后客户 ID |

#### mkt_channel（渠道）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键 |
| channel_name | VARCHAR(50) | 渠道名 |
| channel_type | VARCHAR(20) | 线上/线下 |
| cost | DECIMAL(12,2) | 投入成本 |

#### mkt_knowledge（知识库）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键 |
| title | VARCHAR(200) | 标题 |
| category | VARCHAR(50) | 分类（话术/方案模板） |
| content | LONGTEXT | 内容 |
| attachment_url | VARCHAR(500) | 附件 |

### 2.3 客户管理

#### cus_customer（客户）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键 |
| name | VARCHAR(100) | 客户名称 |
| credit_code | VARCHAR(50) | 统一社会信用代码（查重依据） |
| industry | VARCHAR(50) | 行业 |
| region | VARCHAR(50) | 区域 |
| level | TINYINT | 客户等级 |
| owner_id | BIGINT | 负责人 ID |
| in_pool | TINYINT | 是否在公海 0否 1是 |
| last_follow_time | DATETIME | 最后跟进时间 |
| total_amount | DECIMAL(14,2) | 累计合作金额 |

#### cus_contact（联系人）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键 |
| customer_id | BIGINT | 客户 ID |
| name | VARCHAR(50) | 姓名 |
| position | VARCHAR(50) | 职位 |
| phone | VARCHAR(20) | 电话 |
| is_primary | TINYINT | 是否主联系人 |

#### cus_tag（标签）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键 |
| name | VARCHAR(50) | 标签名 |
| color | VARCHAR(20) | 颜色 |
| type | TINYINT | 1系统 2自定义 |

#### cus_follow_record（跟进记录）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键 |
| customer_id | BIGINT | 客户 ID |
| user_id | BIGINT | 跟进人 |
| follow_type | TINYINT | 1电话 2拜访 3微信 4其他 |
| content | TEXT | 跟进内容 |
| next_follow_time | DATETIME | 下次跟进时间 |
| attachments | VARCHAR(1000) | 附件 URL JSON |

### 2.4 商机与销售

#### biz_opportunity（商机）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键 |
| customer_id | BIGINT | 客户 ID |
| title | VARCHAR(200) | 商机标题 |
| amount | DECIMAL(14,2) | 预计金额 |
| stage | TINYINT | 1需求确认 2方案报价 3商务谈判 4合同签订 5赢 6输 |
| expected_close_date | DATE | 预计成交日 |
| owner_id | BIGINT | 负责人 |
| last_stage_time | DATETIME | 上次阶段变更时间（用于 15 天停滞预警） |

#### biz_contract（合同）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键 |
| opportunity_id | BIGINT | 商机 ID |
| customer_id | BIGINT | 客户 ID |
| contract_no | VARCHAR(50) | 合同编号 |
| amount | DECIMAL(14,2) | 合同金额 |
| sign_date | DATE | 签订日期 |
| approval_status | TINYINT | 1待审批 2审批中 3通过 4驳回 |

#### biz_payment_plan（回款计划）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键 |
| contract_id | BIGINT | 合同 ID |
| plan_date | DATE | 计划回款日 |
| plan_amount | DECIMAL(14,2) | 计划金额 |
| status | TINYINT | 1未回款 2部分 3已回款 |

### 2.5 售后

#### srv_work_order（工单）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键 |
| order_no | VARCHAR(50) | 工单号 |
| customer_id | BIGINT | 客户 ID |
| type | TINYINT | 1咨询 2投诉 3退换货 4安装 5保修 |
| priority | TINYINT | 1低 2中 3高 4紧急 |
| status | TINYINT | 1待处理 2处理中 3待确认 4已关闭 |
| source | VARCHAR(20) | 来源（电话/微信/门店） |
| handler_id | BIGINT | 处理人 |
| satisfaction | TINYINT | 满意度 1-5 |

#### srv_service_record（售后记录）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键 |
| customer_id | BIGINT | 客户 ID |
| work_order_id | BIGINT | 关联工单 |
| type | TINYINT | 1保修 2安装 3退换货 |
| content | TEXT | 处理内容 |

## 三、关键索引

| 表 | 索引 | 字段 |
|---|---|---|
| cus_customer | uk_credit_code | credit_code（唯一，用于查重） |
| cus_customer | idx_owner | owner_id, in_pool |
| mkt_clue | idx_status_owner | status, owner_id |
| biz_opportunity | idx_stage_owner | stage, owner_id |
| srv_work_order | idx_status_handler | status, handler_id |
| sys_log | idx_user_time | user_id, create_time |

## 四、定时任务

| 任务 | 周期 | 作用 |
|---|---|---|
| 客户公海回收 | 每日 02:00 | 30 天未跟进客户 in_pool 置 1 |
| 商机停滞预警 | 每日 09:00 | 15 天未推进商机推送提醒 |
| 回款日提醒 | 每日 09:00 | 临近回款日推送企业微信 |
