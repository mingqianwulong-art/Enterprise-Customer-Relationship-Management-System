## 1. 系统概述与登录

### 1.1 系统简介

本系统是企业客户关系管理（CRM）平台，覆盖市场获客、客户全生命周期管理、商机与销售流程、售后服务、数据分析与系统管理六大模块，支持多角色分级权限管控，帮助企业实现客户资源数字化运营。

### 1.2 登录

1. 打开浏览器，访问系统地址（默认 `http://localhost:5173`）。
2. 输入用户名和密码，点击「登录」。
3. 初始管理员账号：**admin / 123456**，首次登录后请及时修改密码。
4. 忘记密码可点击登录页「忘记密码」链接，通过手机验证码重置。

### 1.3 角色说明

| 角色 | 数据范围 | 核心职责 |
|------|---------|---------|
| 系统管理员 | 全部 | 用户/角色/菜单/部门管理，系统配置 |
| 部门经理 | 本部门及下属 | 团队客户跟进监督、商机审批、数据分析 |
| 销售人员 | 本人 | 客户跟进、商机推进、合同回款、外勤签到 |

## 2. 首页工作台

### 2.1 工作台概览

登录后默认进入工作台，不同角色看到不同内容：

- **管理者**：展示全公司新增客户量、线索转化率、合同总金额、回款进度等核心指标。
- **销售**：展示今日待跟进客户数、本月业绩完成率、个人商机数等。

### 2.2 快捷入口

工作台底部提供快捷入口，可一键跳转至：
- 线索录入
- 客户跟进
- 创建商机
- 发起工单

### 2.3 消息通知

右上角铃铛图标显示未读消息数，点击进入「消息中心」查看：
- 跟进提醒（临近约定跟进时间）
- 商机预警（停滞超15天）
- 回款提醒（3天内到期）
- 系统通知

## 3. 市场获客模块

### 3.1 线索池

**路径**：市场获客 → 线索池

#### 新增线索
1. 点击「新增线索」按钮。
2. 填写线索名称、公司名称、联系电话、来源（展会/门店/抖音/微信/官网/其他）、所属行业、所在区域、等级（高/中/低）、需求描述。
3. 点击「确定」保存。

#### 筛选线索
- 支持按线索名称、来源、等级、**所属行业**、状态多维度筛选。
- 状态颜色含义：
  - 🟡 黄色 = 待分配
  - 🔴 红色 = 待跟进（已分配）
  - 🟢 绿色 = 已转化
  - ⚪ 灰色 = 已废弃

#### 批量操作
1. 勾选列表左侧复选框选中多条线索。
2. 点击「批量分配」输入用户ID，将选中线索分配给同一负责人。
3. 点击「批量导出」将选中线索导出为 CSV 文件（Excel 可直接打开）。

#### 线索分配
- **自动分配**：系统按区域、行业、销售负载自动匹配最佳销售。
- **手动分配**：点击「分配」输入用户ID。
- **抢单**：点击「抢单」将线索领取至自己名下。

#### 线索转化
已分配的线索可转化为正式客户，点击操作列「转化」并关联客户ID。

### 3.2 渠道管理

**路径**：市场获客 → 渠道管理

- 新增渠道：填写渠道名称、类型、投放成本。
- 渠道效果统计：展示各渠道获客量、转化率、ROI。

### 3.3 知识库

**路径**：市场获客 → 知识库

- 新增知识：录入行业话术、活动方案模板，支持分类标签。
- 在线搜索：按标题/分类快速检索。

## 4. 客户管理模块

### 4.1 客户列表

**路径**：客户管理 → 客户列表

#### 新增客户
1. 点击「新增客户」。
2. 填写客户名称、工商信息、联系人、所属行业、区域、合作等级（普通/重要/VIP）。
3. 系统内置查重机制，同名或同电话客户会提示。

#### 筛选客户
- 支持按客户名称、行业、合作等级、**标签**筛选。
- 点击客户名称进入客户详情页。

### 4.2 客户详情

客户详情页采用侧边栏 + 分栏标签设计：

- **侧边栏**：固定展示联系方式、所属行业、合作等级、负责人。
- **跟进记录**标签：查看/新增电话、上门、微信沟通记录，系统自动生成下次跟进提醒。
- **商机列表**标签：查看该客户关联的全部商机。
- **订单回款**标签：查看合同与回款进度。
- **售后工单**标签：查看该客户关联的售后工单。
- **底部快捷操作**：「新增跟进」「创建商机」「发起工单」。

### 4.3 公海池

**路径**：客户管理 → 公海池

- 超过30天未跟进的客户自动流入公海池。
- 销售可「领取」公海客户重新盘活。
- 领取后客户归入自己名下，重新计算跟进倒计时。

### 4.4 标签管理

**路径**：客户管理 → 标签管理

- 新增标签：如「温州制造业」「高复购意向」「3个月未互动」。
- 客户列表支持按标签筛选，精准定位目标群体。

## 5. 商机销售模块

### 5.1 商机管理

**路径**：商机销售 → 商机管理

#### 商机阶段
商机划分为5个阶段：
1. 需求确认
2. 方案报价
3. 商务谈判
4. 合同签订
5. 已赢单

> ⚠️ 超过15天未推进的商机自动触发停滞预警，推送消息提醒负责人。

#### 操作
- 新增商机：关联客户，填写预计金额、预计成交日期。
- 阶段推进：点击「推进」将商机移至下一阶段。
- 销售漏斗：可视化展示各阶段商机数量与转化率。

### 5.2 合同管理

**路径**：商机销售 → 合同管理

- 新增合同：关联客户与商机，填写合同金额、签订日期。
- 合同审批：提交审批流程，管理者审批通过后生效。
- 合同编号自动生成（HT-前缀 + 日期流水）。

### 5.3 回款管理

**路径**：商机销售 → 回款管理

- 新增回款计划：填写计划回款日期、金额。
- 回款确认：实际到账后点击「确认」更新状态。
- > 临近回款日（3天内）自动推送提醒给负责人。

### 5.4 外勤签到

**路径**：商机销售 → 外勤签到

- 上门拜访时点击「签到」，系统记录位置与时间。
- 支持上传现场沟通资料。

## 6. 售后服务模块

### 6.1 工单管理

**路径**：售后服务 → 工单管理

#### 创建工单
1. 点击「新增工单」。
2. 选择客户、填写问题描述、服务类型、优先级（紧急/普通）。
3. 紧急工单自动分配给待处理工单最少的售后人员。

#### 工单处理流程
待处理 → 处理中 → 待反馈 → 已完成 → 已关闭

- **分配**：手动或自动分配给售后人员。
- **状态更新**：处理过程中更新工单状态。
- **满意度评价**：工单完成后自动推送满意度调研，客户评分（1-5分）。

#### 高频问题统计
点击「高频问题」查看售后问题反向溯源报表，同步推送至产品部门。

### 6.2 售后记录

**路径**：售后服务 → 售后记录

- 记录产品保修、上门安装、退换货信息。
- 与客户档案绑定，客服可查看历史服务记录。

## 7. 数据分析模块

### 7.1 数据看板

**路径**：数据分析 → 数据看板

#### 统计卡片
展示6项核心指标：客户总数、线索转化率、商机赢单率、合同总金额、工单处理、公海客户。

#### 图表区域
- **业务增长趋势**：支持「按月」（6/12个月）或「近30天」每日趋势切换，展示新增客户/商机/合同趋势。
- **客户行业分布**：环形图展示行业占比。
- **销售业绩排行**：柱状图对比各销售商机数与赢单数。
- **工单状态分布**：环形图展示工单各状态占比。

#### 下钻交互
- 点击任意图表可跳转至对应明细页面（客户列表、自定义报表、工单管理）。
- 图表标题旁「查看明细」按钮提供明确入口。

### 7.2 自定义报表

**路径**：数据分析 → 自定义报表

- 客户报表：按时间范围、负责人筛选，导出客户分布数据。
- 销售报表：按时间范围统计各销售商机数、合同金额、回款金额、赢单率。

### 7.3 预测分析

**路径**：数据分析 → 预测分析

- **销售趋势预测**：基于历史数据线性回归预测未来销售趋势。
- **高流失风险客户**：识别超阈值天数未跟进的客户，按风险等级排序：
  - 🔴 高风险（>90天）：建议立即安排拜访。
  - 🟡 中风险（>60天）：建议本周内主动联系。
  - 🟢 低风险：建议发送关怀信息。
- **挽留动作**：点击「触发挽留」向负责人发送提醒消息。

## 8. 系统管理模块

> 仅系统管理员可见。

### 8.1 用户管理

**路径**：系统管理 → 用户管理

- 新增用户：填写用户名、姓名、手机、邮箱、部门、角色。
- 编辑/删除：修改用户信息或停用账号。
- 重置密码：管理员重置用户密码。
- 分配角色：为用户指定角色，角色决定权限范围。

### 8.2 角色管理

**路径**：系统管理 → 角色管理

- 新增角色：填写角色名称、角色编码、数据范围（本人/本部门/本部门及下属/全部）。
- 菜单授权：勾选角色可见的菜单与按钮权限。

### 8.3 菜单管理

**路径**：系统管理 → 菜单管理

- 管理菜单层级（目录/菜单/按钮）。
- 配置菜单路径、组件、权限标识、图标。

### 8.4 部门管理

**路径**：系统管理 → 部门管理

- 维护组织架构树，新增/编辑/删除部门。

### 8.5 操作日志

**路径**：系统管理 → 操作日志

- 记录所有登录、修改、删除操作，支持回溯查询。

### 8.6 消息中心

**路径**：系统管理 → 消息中心（或顶部铃铛入口）

- 查看全部消息，按类型筛选（跟进提醒/商机预警/系统通知）。
- 点击消息标记已读，支持「全部已读」。

### 8.7 个人信息与修改密码

- **个人信息**：点击右上角头像 → 个人信息，修改姓名、手机、头像。
- **修改密码**：需验证旧密码，新密码长度不低于6位。

### 9.2 常见问题

**Q：操作按钮灰色不可点击？**
A：当前角色缺少对应按钮权限，请联系管理员在「角色管理」中分配权限，分配后需重新登录刷新权限缓存。

**Q：看不到其他同事的客户数据？**
A：数据权限由角色「数据范围」决定。销售仅可见本人数据，部门经理可见本部门及下属，管理员可见全部。

**Q：客户不见了？**
A：超过30天未跟进的客户会自动流入公海池，可在「客户管理 → 公海池」中领取。

**Q：商机预警如何消除？**
A：推进商机阶段或更新跟进记录后，停滞计时自动重置。

**Q：权限修改后不生效？**
A：权限缓存在 Redis 中，需重新登录刷新。如仍不生效，联系管理员检查 `sys_role_menu` 表是否已正确授权。

**Q：如何导出数据？**
A：线索池支持勾选后「批量导出」CSV；自定义报表页面支持按条件筛选后导出。
