## 一、认证模块

### 1.1 用户登录

| 项目 | 内容 |
|------|------|

| Controller | [AuthController.java](file:///C:/Users/skii/AppData/Roaming/TRAE%20SOLO%20CN/ModularData/ai-agent/work-mode-projects/6a682303f29fc25ee6bef025/backend/crm-system/src/main/java/com/crm/system/controller/AuthController.java) |

## 附录：统一返回格式

所有接口统一返回 `com.crm.common.api.R`：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {}
}
```

| code | 含义 |
|------|------|
| 200 | 成功 |
| 400 | 参数错误/业务校验失败 |
| 401 | 未认证（token 缺失或失效） |
| 403 | 权限不足 |
| 500 | 服务器内部错误 |
