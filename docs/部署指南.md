# CRM 系统部署指南

## 一、Docker Compose 一键部署（推荐）

### 1. 前置要求
- Docker 20.10+
- Docker Compose 2.0+
- 服务器至少 2GB 内存 / 10GB 磁盘

### 2. 配置环境变量
```bash
cd deploy
cp .env.example .env
# 编辑 .env，修改 MySQL 密码、JWT 密钥、短信配置
vi .env
```

### 3. 启动所有服务
```bash
cd deploy
docker-compose up -d --build
```

首次构建需要下载 Maven 依赖，预计 5-10 分钟。

### 4. 查看启动状态
```bash
docker-compose ps
# 等待所有服务 healthy
docker-compose logs -f backend
# 看到 "Started CrmApplication" 表示启动成功
```

### 5. 访问系统
- 前端：http://localhost
- 后端 API：http://localhost:8080
- Swagger 文档：http://localhost:8080/swagger-ui/index.html
- 默认账号：admin / 123456

### 6. 停止与清理
```bash
# 停止服务（保留数据）
docker-compose down

# 停止并删除数据卷（清空数据库）
docker-compose down -v
```

## 二、Docker Compose 服务说明

| 服务 | 容器名 | 端口 | 说明 |
|---|---|---|---|
| mysql | crm-mysql | 3306 | MySQL 8.0，自动执行 deploy/sql/ 下 SQL 初始化 |
| redis | crm-redis | 6379 | Redis 7，持久化存储 |
| backend | crm-backend | 8080 | Spring Boot 后端，连接 mysql/redis 容器 |
| frontend | crm-frontend | 80 | Nginx 托管前端 + 反向代理后端 API |

### 数据持久化
- MySQL 数据：`mysql_data` 卷
- Redis 数据：`redis_data` 卷
- 上传文件：`uploads_data` 卷

### SQL 初始化
MySQL 容器首次启动时自动执行 `deploy/sql/` 下的 SQL（按数字前缀排序）：

| 序号 | 脚本 | 作用 |
|---|---|---|
| 01 | `01-init.sql` | 建库 + 系统模块表 + 初始部门/角色/用户/菜单（username 无唯一索引） |
| 02 | `02-init-customer.sql` | 客户模块表 + 预设标签 |
| 03 | `03-init-market.sql` | 市场模块表 + 测试数据 |
| 04 | `04-init-business.sql` | 商机/合同/回款表 + 测试数据 |
| 05 | `05-init-service.sql` | 工单/售后记录表 + 测试数据 |
| 06 | `06-init-message.sql` | 系统消息表 |
| 07 | `07-init-perms.sql` | 全模块按钮权限 + 6 角色授权 |
| 08 | `08-fix-unique-constraint.sql` | 修复 DEFAULT '' + UNIQUE 冲突（改 DEFAULT NULL） |
| 09 | `09-fix-menu-perms.sql` | 统一菜单权限标识 + 销售经理菜单授权 |
| 10 | `10-fix-register-unique.sql` | 注册功能 phone NOT NULL + uk_phone/uk_email |
| 11 | `11-fix-opportunity-stagnant.sql` | bus_opportunity 添加 stage_change_time 字段 |
| 12 | `12-fix-password.sql` | 修复测试账号密码哈希 |
| 13 | `13-init-testdata.sql` | 测试数据补充 |
| 14 | `14-init-sign-in.sql` | 外勤签到表 + 菜单 + 全角色授权 |
| 15 | `15-fix-user-assign-perm.sql` | 分配角色按钮权限（system:user:assign） |
| 16 | `16-fix-menu-name.sql` | 修复被 PowerShell 编码破坏的菜单名称 |
| 17 | `17-add-owner-id-index.sql` | 合同/回款表 owner_id 索引 |
| 18 | `18-fix-username-dept-unique.sql` | 移除 sys_user.uk_username（允许跨部门同名） |
| 19 | `19-fix-user-unique-after-delete.sql` | 清理逻辑删除用户的 phone/email 占用 |

> 原始脚本同步保存在 `docs/sql/` 下（无数字前缀），二者内容一致。

## 三、单独构建部署

### 只部署后端
```bash
cd deploy
docker build -f backend.Dockerfile -t crm-backend .. 
docker run -d --name crm-backend -p 8080:8080 \
  -e SPRING_DATASOURCE_URL=jdbc:mysql://host.docker.internal:3306/crm_db \
  -e SPRING_DATASOURCE_USERNAME=root \
  -e SPRING_DATASOURCE_PASSWORD=12345678 \
  -e SPRING_DATA_REDIS_HOST=host.docker.internal \
  crm-backend
```

### 只部署前端
```bash
cd deploy
docker build -f frontend.Dockerfile -t crm-frontend ..
docker run -d --name crm-frontend -p 80:80 crm-frontend
```

## 四、生产环境注意事项

### 1. 修改默认密码
首次登录后立即修改 admin 账号密码。

### 2. 配置 HTTPS
在 Nginx 配置中添加 SSL 证书：
```nginx
server {
    listen 443 ssl;
    server_name your-domain.com;
    ssl_certificate     /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;
    # ... 其余配置同 nginx.conf
}
```

### 3. 配置短信服务
在 `.env` 中填入阿里云短信配置：
```
SMS_ENABLED=true
SMS_ACCESS_KEY_ID=your-access-key
SMS_ACCESS_KEY_SECRET=your-secret
SMS_SIGN_NAME=your-sign
SMS_TEMPLATE_CODE=your-template
```

### 4. 数据库备份
```bash
# 备份
docker exec crm-mysql mysqldump -uroot -p crm_db > backup.sql

# 恢复
docker exec -i crm-mysql mysql -uroot -p crm_db < backup.sql
```

### 5. 查看日志
```bash
# 后端日志
docker logs -f crm-backend

# 前端 Nginx 日志
docker logs -f crm-frontend
```
