# 企业客户关系管理系统（CRM）需求文档

> 本文档基于《企业客户关系管理系统建设方案》结构化整理而成，作为开发与验收依据。

## 一、项目背景

面向温州本地企业的一体化 CRM 系统，覆盖**市场获客 → 客户管理 → 商机跟进 → 售后服务 → 数据决策**全链路，解决多渠道线索散落、客户资源闲置、销售过程不透明、售后响应慢等痛点。

## 二、用户角色

| 角色 | 主要权限 | 典型场景 |
|---|---|---|
| 系统管理员 | 全量操作 + 系统配置 | 用户/角色/权限、第三方集成配置 |
| 部门经理 | 查看团队数据 + 分配资源 | 团队业绩、商机推进、线索分配 |
| 销售（PC + 移动端） | 仅看自己负责的客户 | 客户跟进、商机推进、外勤签到 |
| 市场人员 | 线索录入 + 知识库管理 | 多渠道线索归集、活动效果分析 |
| 售后客服 | 工单处理 + 客户档案查看 | 工单分配、售后记录追溯 |
| 产品部门 | 数据看板 + 问题溯源报表 | 高频售后问题统计 |

## 三、功能模块清单

### 模块 1：市场获客

| 编号 | 功能 | 描述 | 优先级 |
|---|---|---|---|
| M1-01 | 多渠道线索归集 | 对接温州展会、线下门店、抖音/微信公域、官网表单，自动同步至线索池 | P0 |
| M1-02 | 渠道效果分析 | 多维看板：获客量、获客成本、成交转化率 | P1 |
| M1-03 | 线索智能分配 | 按区域/行业/销售能力自动分配，1 分钟内推送；支持抢单、退回 | P0 |
| M1-04 | 业务知识库 | 行业话术、活动方案模板沉淀与共享 | P2 |

### 模块 2：客户全生命周期管理

| 编号 | 功能 | 描述 | 优先级 |
|---|---|---|---|
| M2-01 | 客户基础信息管理 | 工商信息、联系人、合作记录、回款；名称/行业/金额检索；数据查重 | P0 |
| M2-02 | 标签与分组 | 自定义标签（如"温州本地制造业""3 个月未互动"），一键筛选推送 | P0 |
| M2-03 | 跟进过程留痕 | 电话/拜访/微信沟通记录，自动生成下次跟进提醒，临近推送通知 | P0 |
| M2-04 | 公海池机制 | 超 30 天未跟进自动流入公海，他人可领取盘活 | P0 |

### 模块 3：商机与销售流程

| 编号 | 功能 | 描述 | 优先级 |
|---|---|---|---|
| M3-01 | 商机分阶段管控 | 需求确认 → 方案报价 → 商务谈判 → 合同签订；超 15 天未推进预警 | P0 |
| M3-02 | 销售漏斗可视化 | 各阶段商机数量与转化率 | P1 |
| M3-03 | 合同与回款管理 | 合同模板、在线审批、自动回款计划、应收款可视化 | P0 |
| M3-04 | 移动端外勤支持 | 签到打卡、现场上传资料、离线录入、联网同步 | P1 |

### 模块 4：售后与服务

| 编号 | 功能 | 描述 | 优先级 |
|---|---|---|---|
| M4-01 | 智能工单系统 | 电话/微信/门店提交 → 自动生成工单 → 按类型/优先级分配 → 满意度调研 | P0 |
| M4-02 | 售后全记录关联 | 保修、安装、退换货与客户档案绑定，客服可查历史 | P0 |
| M4-03 | 问题反向溯源 | 高频问题统计报表，推送至产品部门 | P2 |

### 模块 5：数据分析与决策

| 编号 | 功能 | 描述 | 优先级 |
|---|---|---|---|
| M5-01 | 多维自定义报表 | 客户分布、销售业绩、渠道 ROI、售后响应时效 | P1 |
| M5-02 | 可视化数据看板 | 业绩完成率、客户新增量、回款进度实时展示 | P0 |
| M5-03 | 预测分析 | 销售趋势预测、高流失风险客户识别、挽留动作触发 | P2 |

### 模块 6：系统基础管理

| 编号 | 功能 | 描述 | 优先级 |
|---|---|---|---|
| M6-01 | 分级权限管控 | RBAC：销售看自己、经理看团队、管理员全量 | P0 |
| M6-02 | 操作日志审计 | 登录/修改/删除全程留痕，可回溯查询 | P0 |
| M6-03 | 第三方集成 | ERP、财务软件、企业微信数据互通 | P1 |

## 四、页面设计要求

整体风格：简洁易用，**主色调蓝色系 + 浅灰辅助色**，界面清晰降低学习成本。

| 编号 | 页面 | 关键要素 |
|---|---|---|
| P1 | 首页工作台 | 顶部导航（消息/待办/快捷入口）；核心数据卡片（角色差异化）；动态信息流（点赞评论）；可自定义组件区 |
| P2 | 客户详情 | 左侧基础信息侧边栏；分栏标签（跟进记录/商机/订单回款/售后工单）；底部固定快捷操作按钮 |
| P3 | 线索池 | 顶部多维度筛选；卡片列表 + 批量勾选 + 一键分配；颜色状态标识（红/绿/黄） |
| P4 | 数据分析看板 | 环形图（行业分布）+ 折线图（30 天新增）+ 柱状图（业绩对比）；下钻交互；定时推送企业微信 |
| P5 | 移动端适配 | 响应式布局；按钮放大防误触；首页优先展示外勤/待办/扫码；离线缓存 |

## 五、非功能性需求

| 维度 | 要求 |
|---|---|
| 性能 | 列表查询 ≤ 1s；线索分配 ≤ 1 分钟推送 |
| 可用性 | 离线模式下核心录入可用，联网自动同步 |
| 安全 | 操作审计；数据分级权限；登录鉴权；密码安全策略：密码长度 8-20 位，必须包含大小写字母、数字和特殊字符；初始默认密码 @Abc1234，首次登录后强制修改；支持通过手机验证码重置密码和旧密码验证修改密码 |
| 兼容 | PC 端主流浏览器 + 移动端 H5 适配 |
| 集成 | 预留 ERP/财务/企业微信对接接口 |
